# Scholarship Sahayata Dashboard

A comprehensive government scholarship tracking dashboard with Aadhaar and DBT integration analysis.

## How to Run in VS Code

1.  **Install Node.js**: Ensure you have Node.js installed on your system.
2.  **Open Terminal**: Open the terminal in VS Code (`Ctrl + ~`).
3.  **Install Dependencies**: Run the following command to install the required packages:
    ```bash
    npm install
    ```
4.  **Run Development Server**: Start the local server:
    ```bash
    npm run dev
    ```
5.  **Open App**: Click the link shown in the terminal (usually `http://localhost:3000`) to view the app in your browser.
